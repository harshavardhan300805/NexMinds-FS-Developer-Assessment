# A. Harsha Vardhan — Full Stack Developer Assessment Portfolio

## Assessment coverage

This portfolio is designed around the provided interview assessment:

- Professional, structured personal portfolio
- Integrated social/contact links: GitHub, LinkedIn and email
- Modern web technologies and browser APIs relevant to a full-stack/web profile
- Detailed implementation documentation
- Responsive and mobile-friendly design
- Accessibility-minded semantic HTML and reduced-motion support
- Original visual design and portfolio content

## Technology

### Core
- HTML5 semantic markup
- CSS3 with custom properties, Grid, Flexbox, gradients, responsive breakpoints and `backdrop-filter`
- Vanilla JavaScript

### Browser/platform capabilities
- Canvas API for the hero visual
- IntersectionObserver for progressive reveal animations
- Responsive navigation for small screens
- `prefers-reduced-motion` accessibility support
- Lazy-loaded certificate images
- SEO-friendly metadata and descriptive image alt text

No framework or build step is required. This keeps deployment simple for static hosting such as GitHub Pages.

## Main sections

1. Hero — identity, profile summary and social links
2. About — practical development focus
3. Technology — programming, web, AI/ML, cloud/data, design and advanced web capabilities
4. Experience — internship timeline and responsibilities
5. Projects — Wellness Cycle, Personal Portfolio and Digital Portfolio Hosting System
6. Credentials — selected job simulations and certificates
7. Implementation — architecture, design system, browser APIs, responsive engineering and performance decisions
8. Contact — direct email CTA

## Design approach

The visual theme uses a dark technical interface with cyan/violet accents, glass-like panels and strong typographic hierarchy. The goal is to look distinctive while keeping project information easy for an interviewer to scan.

## Deployment

The site is static and can be deployed by uploading the project folder to GitHub Pages or another static hosting provider.

## Original work

The portfolio layout, styling, interaction code and documentation are custom-built for this assessment. Profile facts, internships, projects and credentials are presented from the information supplied for the portfolio and should be kept accurate.
